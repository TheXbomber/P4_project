# port 2 = toward H (h3/h4, for end_of_chain delivery)

# SPI=13 chain at D:
#   arriving SI=3 → proxy_to_sf SF1 (port 0)
#   SF1 returns bare port 0, meta.spi=13 → proxy_return_to_core SI=2 label=102 toward F
